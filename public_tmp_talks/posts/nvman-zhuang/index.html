mac通过<

nvm安装 font style="color:rgb(38, 38, 38);">Homebrew安装nvm

  1. 下载Homebrew

Homebrew官网

  1. 安装nvm
brew install nvm
  1. 配置nvm环境变量

安装完成后，需要配置nvm的环境变量。打开你的shell配置文件（如~/.zshrc或~/.bash_profile），并添加以下内容

export NVM_DIR="$HOME/.nvm"
[ -s "$(brew --prefix nvm)/nvm.sh" ] && \. "$(brew --prefix nvm)/nvm.sh"

保存文件后，重新加载配置文件：

source ~/.zshrc # 或者 source ~/.bash_profile
  1. 验证安装
nvm -v

linux安装nvm

  1. 在线安装
curl -o- https://raw.githubusercontent.com/creationix/nvm/v0.33.11/install.sh | bash
#或者 如果wget不存在 执行yum -y install wget
wget -qO- https://raw.githubusercontent.com/creationix/nvm/v0.33.11/install.sh | bash
  1. 本地安装
#从官网下载安装
官网地址：https://github.com/nvm-sh/nvm/archive/refs/tags/v0.39.1.tar.gz

#将压缩包上传至服务器，如我当前位置/nvm

#新建服务器nvm地址
mkdir /root/.nvm

#将压缩包解压至/root/.nvm
tar -zxvf nvm-0.39.1.tar.gz --strip-components 1  -C /root/.nvm
  1. 在bashrc里面写下相关配置(使用在线安装跳过这步)
#编辑文件
vim ~/.bashrc

#写入配置
export NVM_DIR="$HOME/.nvm"
[ -s "$NVM_DIR/nvm.sh" ] && . "$NVM_DIR/nvm.sh" # This loads nvm
  1. 刷新配置即可正常使用
#刷新配置
source ~/.bashrc

#判断nvm是否安装
nvm -v
  1. 使用nvm下载相关node版本
nvm install 14.13.2

#nvm常用命令
nvm uninstall 14.13.2     // 移除 node 14.13.2
nvm use 14.13.2           // 使用 node 14.13.2
nvm ls                   // 查看目前已安装的 node 及当前所使用的 node
nvm ls-remote            // 查看目前线上所能安装的所有 node 版本
nvm alias default 14.13.2 // 使用 14.13.2 作为预设使用的 node 版本

window 安装

  1. 下载 nvm-setup，并安装 nvm

  1. 如果 nvm 不能下载 14.17.5 版本， 可以在 node 历史版本直接下载，下载后可以放在 nvm 目录中

node 历史版本：https://nodejs.org/dist/

  1. 环境变量配置后，需要关闭终端，重新打开。
